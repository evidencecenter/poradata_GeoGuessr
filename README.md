# Географическая угадайка

Геогессер по местам российской Арктики. В каждом раунде три фотографии одного места: нужно понять, где они сделаны, и выбрать этот регион на карте.

Совместный проект ПОРА и АНО «Тривиум».

## Как играть

1. В игре 10 раундов, в каждом три снимка одного места.
2. Нажмите на регион, где, по-вашему, сделаны фотографии. Цветом выделены 10 регионов, которые участвуют в игре, названия появляются при наведении курсора.
3. После ответа правильный регион подсвечивается синим, неверный ответ оранжевым, а точка с подписью показывает загаданное место.
4. В конце игра показывает, какую долю регионов удалось угадать.

## Запуск

Вся игра в одном файле `index.html`, без зависимостей и сборки. Его можно открыть в браузере или опубликовать через GitHub Pages: Settings → Pages → Deploy from a branch → `main`, папка `/ (root)`.

Вёрстка адаптирована под телефоны: на узком экране снимки листаются горизонтально, карта масштабируется кнопками.

## Как устроено

- **Карта.** Встроенный SVG с контурами 89 субъектов РФ в проекции Альберса (стандартные параллели 50° и 70° с. ш., центр 56° с. ш., 100° в. д.). Выбрать можно только 10 регионов с классом `azrf`.
- **Ответ.** Засчитывается, если выбранный регион совпадает с регионом раунда: сравниваются `data-name` контура и поле `region`.
- **Раунды.** Массив `ROUNDS` в скрипте. Счётчик раундов и шкала прогресса пересчитываются по его длине.
- **Фото с Викисклада.** Подгружаются по имени файла шириной 800 px. Под каждым снимком выводятся автор, лицензия и ссылка на оригинал.
- **Фото ПОРА.** Встроены в файл в формате base64, объект `OWN_PHOTOS`.

## Как добавить или заменить место

Каждый раунд описывается объектом в `ROUNDS`:

```js
{
  answer: 'Плато Путорана',     // подпись места после ответа
  region: 'Красноярский край',  // как в data-name контура на карте
  lat: 68.2078, lon: 92.7706,   // где поставить точку
  photos: [ /* три снимка */ ]
}
```

Снимок с Викисклада:

```js
{ file: 'Teriberka.jpg', author: 'Dmitry A. Mottl', license: 'CC BY-SA 4.0',
  source: 'https://commons.wikimedia.org/wiki/File:Teriberka.jpg' }
```

Собственный снимок: ключ из `OWN_PHOTOS` и подпись.

```js
{ own: 'pora-waterfall-1', author: 'Фото: ПОРА', title: 'Водопад среди базальтовых уступов' }
```

Поле `title` идёт в альтернативный текст снимка. Лицензии из объекта `LICENSES` получают ссылку на свой текст.

## Источники

- Фотографии: Wikimedia Commons (авторы и лицензии указаны под каждым снимком в игре) и ПОРА.
- Карта: региональные геоданные.
